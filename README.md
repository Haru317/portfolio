# Clair de Lune Portfolio

A responsive static portfolio built with Vite. The original Notion portfolio remains unchanged and serves only as source material.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Cloudflare Pages settings:

- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`
